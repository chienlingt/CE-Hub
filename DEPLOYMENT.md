# IIS Deployment Guide - lab2.tbm2u.net

## First-Time Setup (Do Once)

### On IIS Server:

```powershell
# 1. Clone repository
cd C:\inetpub\wwwroot
git clone <your-repo-url> fyp_logistics
cd fyp_logistics

# 2. Create .env files
Copy-Item "client\.env.production" "client\.env"
Copy-Item "server\.env.production" "server\.env"

# 3. Edit server .env
notepad server\.env
```

Update `server\.env`:
```bash
DATABASE_URL=postgres://postgres:tbm2u@lab.tbm2u.net:5432/logistics?schema=public
CLIENT_URL=https://lab2.tbm2u.net
JWT_SECRET=your-strong-random-secret-here
NODE_ENV=production
```

```powershell
# 4. Run IIS setup (as Administrator)
.\server-setup.ps1

# 5. Run deployment
.\deploy-to-iis.ps1

# 6. Assign SSL certificate in IIS Manager
```

**Done!** Test at: https://lab2.tbm2u.net

## Update Deployment (Every Time)

```powershell
# 1. Pull latest code
cd C:\inetpub\wwwroot\fyp_logistics
git pull

# 2. Deploy (Run PowerShell as Administrator)
.\deploy-to-iis.ps1
```

That's it! The script automatically:
- ✅ Stops IIS app pool
- ✅ Builds React client
- ✅ Installs/updates npm packages
- ✅ Generates Prisma Client
- ✅ Starts IIS app pool

## Troubleshooting

### Check if services are running:
```powershell
Import-Module WebAdministration
Get-WebAppPoolState -Name "TBMDeliveryAPI"
Get-Website -Name "TBMDelivery" | Select Name, State
```

### Check logs:
```powershell
# Node.js errors
Get-Content "server\iisnode\*-stderr-*.txt" -Tail 50

# Restart app pool
Restart-WebAppPool -Name "TBMDeliveryAPI"
```

### Common Issues:

| Problem | Solution |
|---------|----------|
| 503 Error | App pool stopped - run `Start-WebAppPool -Name "TBMDeliveryAPI"` |
| 403 Error | Wrong physical path - should be `client\build` not `client` |
| EPERM Error | Run PowerShell as Administrator before deploy |
| Login fails | Clear browser cache (Ctrl+Shift+R) |
